## 🔄 Conversion Formula

### Celsius

```
°F = (°C × 9/5) + 32
K  = °C + 273.15
```

### Fahrenheit

```
°C = (°F − 32) × 5/9
K  = °C + 273.15
```

### Kelvin

```
°C = K − 273.15
°F = (°C × 9/5) + 32
```
